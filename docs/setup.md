# Installation

## Manual Installation

### Download Oggun

Download the oggun source code by clicking the following link or invoking the following command.

[https://github.com/nikowa/oggun/archive/refs/heads/master.zip](https://github.com/nikowa/oggun/archive/refs/heads/master.zip)

```txt
git clone https://github.com/nikowa/oggun.git
```

### Install Oggun

Intall oggun by invoking the following commands or by manually copying `shared/oggun` to `<odin-dir>/shared/oggun`.

```txt
cd oggun
odin build shared/oggun -out:oggun.exe
./oggun.exe install
```
